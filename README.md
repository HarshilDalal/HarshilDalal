## 👨‍💻 About Me

I'm a **Frontend & Full Stack Developer** completing an **M.Eng. in Industrial Informatics** at Hochschule Emden/Leer, Germany. I build production-grade web applications, IIoT systems, and AI-integrated frameworks.

My current focus is on **AAS-driven dynamic UI frameworks** for modular digital factory environments — combining modern frontend architecture with Industry 4.0 protocols.
